Munin

A news reader for Indian newsrooms.

Stack
React 19, TypeScript, TanStack Start, RSS
Visit Site →

The problem

Following many Indian newsrooms means juggling dozens of apps and feeds, with no calm way to read across all of them.

What I built

Munin gathers live headlines from roughly 110 Indian newsrooms and lays them out in one feed — read it as a feed, a reels-style stack, or by topic. Save stories, follow the newsrooms you trust, and write your own take; bookmarks, history, posts and theme are kept on your device.

How I built it

React 19 + TanStack Start with SSR, pulling headlines from ~110 RSS feeds server-side, with reading state kept in localStorage.

Key decisions

  • No accounts and no backend — reading state is kept on your device, so there is nothing to sign up for.
  • Offered several reading modes (feed / reels / topic) because people read news differently depending on the moment.

Result

An account-free reader built on React 19 + TanStack Start with SSR, pulling a genuinely wide set of Indian newsrooms into one place.
