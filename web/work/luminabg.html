LuminaBG

Seven background-removal engines in one app — including one that never uploads your image.

Stack
React 19, Vite, Hugging Face, remove.bg
Visit Site → View source →

The problem

Background removal looks solved until you use it for real. The best-quality model is slow, the fastest one mangles hair, and most tools quietly upload your image to someone else's server to do it. Pick one engine and you inherit whichever trade-off it made.

What I built

An app that runs seven engines side by side and lets you choose per image — a zero-upload mode that processes entirely inside the browser tab, hosted models for the hardest edges, and a one-click cloud option. It adds a before/after compare view, alpha matting for hair and fur, and transparent-PNG export.

How I built it

React 19 + Vite on the front end, with the in-browser engine running segmentation locally in the tab. The heavier models — U2-Net, ISNet and BiRefNet — run on Hugging Face ZeroGPU, and remove.bg covers the no-setup path. Every engine is normalised behind one input/output contract.

Key decisions

  • Made engine choice a first-class control instead of picking for the user — quality, speed and privacy are genuinely different jobs.
  • Built the in-browser engine first, because "your image never leaves this tab" is a promise no hosted API can make.
  • Normalised every engine behind one contract, so adding an eighth is a plugin rather than a rewrite.

Result

Shipped and open source, with stars on GitHub. The interesting part is not the cutout — it is proving that one app can serve privacy, speed and quality at once instead of asking the user to pick a compromise.
