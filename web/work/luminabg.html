LuminaBG

A hybrid AI background remover that refuses to lock you into one engine.

Stack
React 19, Vite, Hugging Face, remove.bg
Visit Site → View source →

The problem

Most background removers force one model or one paid API on you — and many upload your image to a server even when a quick browser-only pass would have done the job.

What I built

An app that offers seven engines per image: a zero-upload browser engine (your image never leaves the tab), a cloud API, and several open-source models. It adds a before/after compare view, optional alpha matting for hair and fur, and transparent-PNG export.

How I built it

React 19 + Vite on the front end. Background removal runs across seven engines — a zero-upload in-browser model, the remove.bg cloud API, and open-source models (U2-Net, ISNet, BiRefNet) hosted on Hugging Face ZeroGPU.

Key decisions

  • Made engine choice a first-class feature instead of hiding it — quality, speed and privacy are genuinely different needs.
  • Offered a fully local option so privacy-sensitive users never have to trust a server with their image.

Result

Shipped, with a growing set of stars on GitHub. The point was to show that a single app can serve privacy, speed and quality rather than picking one for the user.
