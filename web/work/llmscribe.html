llmScribe

An open-source tool that turns a local codebase into structured, deterministic context for coding agents.

Stack
Python, MCP, CLI, PyPI
Visit Site → View source →

The problem

Coding agents don't have an intelligence problem, they have a retrieval problem. On a large codebase they read hundreds of files to change one line, re-read the same files in a loop, and miss the file that actually mattered, because the context going into the window is unstructured.

What I built

An MCP server that gives agents a small, deterministic toolset instead of free-form file reading: map a project without dumping its contents, search paths and contents, read one file or many, trace dependencies in both directions, inspect the git diff, and export an overview. Nothing is inferred, embedded or ranked, and every truncation is reported.

How I built it

Pure Python, published on PyPI under Apache-2.0. One core engine powers three interfaces — a CLI, a desktop GUI and a local stdio MCP server — so behaviour stays identical everywhere.

Key decisions

  • Kept the output deterministic and transparent: same input, same bytes, and every cut reported, so you can see exactly what goes to the model.
  • Made it local-only, so a private codebase never has to be uploaded to a service to be read.
  • Shipped three interfaces from one core so it fits both humans and agents.

Result

Open-source on PyPI under Apache-2.0 and listed on the official MCP Registry, with stars on GitHub and real use as an MCP server. It is the project that best shows the Python-plus-system-design side of how I work.
