How I Build

I vibe code: I bring the architecture, product thinking, and Python; AI helps write the code. My job is knowing what to build, how it fits together, and how to ship it so it scales.

  • 1. Design the system

    Architecture first

    Services, data flow, database, and APIs are sketched before the first prompt, so the AI builds into a plan instead of guessing.

  • 2. Direct the AI

    Prompt with intent

    Clear context, constraints, and goals — and I review, question, and test everything the AI writes.

  • 3. Deploy & iterate

    Ship early, improve constantly

    Containerized, deployed, and monitored. Real users and real logs drive the next iteration.

About Me

I'm a self-taught builder and vibe coder. Python is the language I actually know, and I pair it with a solid grasp of system architecture, scalable deployment, and how AI fits into real products. I don't chase syntax — I design the system, direct AI to write the code, review it like an engineer, and ship it. That's how I've gone from Python tooling to React/TypeScript dashboards to Flutter apps.

Lately I've been deep in AI-assisted workflows — building tools like llmScribe that help AI models understand codebases faster, and products like Hakertrade and NewsReels that put useful technology directly in front of users. I like taking a messy idea and turning it into something structured, fast, and actually usable.
