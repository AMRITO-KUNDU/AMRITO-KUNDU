About Me

I'm a self-taught builder. Python is the language I know best — I use it for tools and backends, and I lean on AI to write and review code in other languages when a project needs them. My work style is simple: describe the idea, steer the AI, review what comes back, test it, ship it. Some people call that vibe coding; I call it keeping the loop short and the system small. I like taking an idea and turning it into something that works.
