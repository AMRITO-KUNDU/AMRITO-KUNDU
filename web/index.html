Scoop

A family-admin app that turns school chaos into a plan. Paste a school email, WhatsApp thread or newsletter and Scoop uses Groq tool-calling — not chat — to pull the events, deadlines, tasks and RSVPs into one editable list, with Today/This-Week filters, .ics and Google Calendar export, and Google Calendar/Tasks sync via Composio. Silver Award, CSC Back-to-School Hackathon; selected for Hackyard Build 2026 at IIT Guwahati.

llmScribe

An open-source Python tool that turns any codebase into clean, structured, deterministic data for LLMs — no AI, no embeddings, no hidden ranking. It maps a project, searches it, and retrieves exactly what you need; it's dependency-aware and git-aware, and works on local folders or public GitHub repos without cloning. Ships as a CLI, a GUI, and a hosted MCP server for AI agents.

No backend, no database: drop images into a folder, push, and a GitHub Action regenerates the catalog. Auto light/dark theming, favorites, and pinch-zoom.

Munin

An RSS-powered news reader that gathers live headlines from ~110 Indian newsrooms server-side and lays them out in one calm feed — read it as a feed, a reels-style stack, or by topic. Save stories, follow the newsrooms you trust, and write your own take; bookmarks, history, posts and theme all live in localStorage, so there is no account and no backend. React 19 + TanStack Start with SSR.
